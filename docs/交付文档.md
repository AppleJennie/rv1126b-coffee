## 二、整机工作流程（一次订单）

```
屏幕点单 POST /api/order → 板子排队 → 机械臂：视觉找杯(纠偏) → 抓杯 → 放到滴滤机
  → WiFi 开磨豆机(插座通电15s) → 倒粉(腕部分3步慢倒) → WiFi 按滴滤机(点动1s)
  → 等冲泡180s → 递杯出品 → 回待机
全程进度由 SSE 实时推到屏幕（取杯→磨豆→冲泡→出品）
```

任意一步失败 → 全臂卸力保护 + 报错定位到具体状态/舵机 + 屏幕收到 error 事件。
电器 WiFi 控制与网页通讯的详细设计见 `docs/WiFi控制与网页通讯设计.md`。

## 五、待办（真机回来后按序做）

1. 板子插回 → 确认 `/dev/ttyACM0`（波特率 **1500000**）
2. IMX335 摄像头插板子 USB2.0 Type-A 大口 → `v4l2-ctl --list-devices` 认 `/dev/video52`
3. 部署上板 → 采图/杯检测/舵机扫描自检（`fsm.py check`）
4. 手掰示教录 8 个姿态（`fsm.py teach <姿态名>`）→ 手眼标定 → 真机跑 `fsm.py run`
5. 模型按 RV1126B 重转（rknn-toolkit2 **仅有 x86_64 Linux 版**，板端只能推理不能转换；
   可选：Mac 上 Docker Desktop 跑 amd64 容器 / Google Colab / 任意 x86 机器）；
   Mac 上跑 `gen_audio_mac.sh` 生成语音 wav
6. 买 WiFi 插座/点动继电器（Tasmota 或 Sonoff DIY），绑固定 IP 改 `config.json` 的 host；
   确认两台机器开关类型选 power/press 模式；板子配 wpa_supplicant 连 WiFi
7. 板端自启 `kiosk_server.py` + 屏幕浏览器指向 `http://127.0.0.1:8080/`
