## 二、机械结构（6 自由度）

```
底座旋转(J1) → 肩俯仰(J2) → 肘俯仰(J3) → 腕俯仰(J4) → 腕旋转(J5) → 夹爪(J6)
```

- 臂展 30–40cm 足够覆盖"咖啡机 ↔ 取杯位"工作台
- 大关节（肩肘）务必加法兰轴承，别让舵机轴直接承受径向弯矩

## 三、电气拓扑

```
12V 适配器 → ATK-DLRV1126B
8.4V 电源 → [急停按钮] → 舵机转接板电源口 → 6 个舵机（总线串联）
板子 USB 口 → USB转TTL → 舵机转接板信号口（半双工 TTL，共地！）
USB 摄像头 → 板子 USB 口
```

**共地是铁律**：舵机电源 GND、转接板 GND、开发板 GND 必须连在一起。

- 真机验收：接线后 `./servo_tool scan` 能找到舵机、`move` 让舵机平滑摆动

### 阶段 1：整臂标定与单关节运动（3–5 天）
- 装臂，逐个关节调零位和行程限位（软件软限位必须写）
- 关节空间插值运动（起点→终点平滑过渡）

### 阶段 2：运动学（3–5 天）
- 正运动学（DH 参数法）
- 逆运动学：建议把腕部约束为"夹爪始终水平"，降为 4 轴解析解，简单可靠

### 阶段 3：示教编程做咖啡流程（2–3 天，本项目的大招）
- 总线舵机支持卸力后**手掰示教**：卸力 → 手拖动臂走一遍流程 → 记录各关键点位置 → 保存为路点表
- 胶囊机流程路点：待机位 → 取杯位 → 放杯到出水口下 → 按启动键位 → 等待（定时）→ 取杯 → 送出位
- 每步加失败检测：夹爪电流、关节位置回读超差报警

### 阶段 4：视觉纠偏（1–2 周，可选增强）
- OpenCV Hough 圆检测杯口（白纸杯场景足够，不用上深度学习）
- 要更强的识别再上 RKNN（板子 NPU 的主场，但第一阶段不需要）
- 手眼标定：像素坐标 → 臂基坐标（eye-to-hand，相机固定俯视工作台最简单）
